\# Proyecto de Análisis de Datos - Titanic (Kaggle)



\## Descripción

Este proyecto realiza un análisis de calidad y exploración de datos del dataset `gender\_submission.csv` perteneciente a la competencia del Titanic en Kaggle.



\## Estructura del Proyecto

\- `analisis.py`: Script principal de Python para cargar y analizar los datos.

\- `gender\_submission.csv`: Dataset original descargado de Kaggle.

\- `requirements.txt`: Archivo con las librerías necesarias.

\- `.gitignore`: Configuración para ignorar archivos no deseados en Git.
